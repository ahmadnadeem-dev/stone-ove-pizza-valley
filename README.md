# Stone Ove Pizza Valley — Restaurant Website Redesign

A modern restaurant website redesign for **Stone Ove Pizza Valley**, a pizza chain in Pakistan (Chiniot, Lahore, Faisalabad and more cities) — wood-fired pizzas, burgers, wings and deals, open daily 11 AM to 2 AM.

## What's inside

- Full single-page website in one `index.html` — hero, menu, deals and locations
- Food menu with categories: pizzas, burgers, wings, fried chicken, sides and desserts
- **Working order cart** — add items, adjust quantities and review the order on the page
- Fully responsive layout for mobile, tablet and desktop
- Food photography embedded directly in the page (single self-contained file, no external assets)

## Built with

- HTML5
- CSS3
- JavaScript (no framework)
